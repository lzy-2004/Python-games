# Python 小游戏开发  
## 游戏列表  
本项目是一个基于 pygame 开发的多款经典小游戏集合，包含以下游戏：
- 2048
- 俄罗斯方块
- 贪吃蛇
- 跳一跳
- 连连看  
## 游戏功能说明  
1. 2048  
- 控制方向键合并数字，目标是达到 2048。
- 支持重新开始按钮和最高分记录。  

2. 俄罗斯方块  
- 经典俄罗斯方块玩法，使用方向键控制方块移动、旋转。
- 支持暂停、继续和重新开始。  

3. 贪吃蛇  
- 控制蛇头移动，吃食物增长身体，避免撞墙或咬到自己。
- 支持得分、暂停功能。  

4. 跳一跳  
- 按下空格键小鸟向上跳跃，松开后，小鸟受重力影响向下坠落。
- 小鸟需要躲避管道，否则游戏失败。  

5. 连连看  
- 点击两个相同图标进行消除。
- 消除后图标下落，形成新的排列。
